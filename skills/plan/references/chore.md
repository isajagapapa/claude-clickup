# Chore plan

Maintenance work: dependencies, config, infrastructure, tooling.

1. **Change**: exactly what is upgraded, added, removed or reconfigured, with versions.
2. **Impact**: code, environments and team members affected, breaking changes from changelogs.
3. **Steps**: ordered commands and edits.
4. **Verify**: build, tests and the app still work in each affected environment.
5. **Rollback**: how to undo it quickly.
