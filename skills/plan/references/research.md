# Research plan

Answer a question or reduce uncertainty. The output is findings and a recommendation, not production code.

1. **Question**: what exactly needs answering and what decision it unblocks.
2. **Options**: candidate approaches, libraries or services to compare.
3. **Criteria**: how options are judged (effort, cost, performance, risk, fit with the current stack).
4. **Method**: code to read, docs to check, small prototypes or benchmarks to run, and where throwaway code lives.
5. **Timebox**: how long to spend before reporting back.
6. **Deliverable**: findings, a recommendation, and follow-up cards to create.
