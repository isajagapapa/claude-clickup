# Feature plan

Something new that does not exist yet.

1. **Scope**: what is in and what is out. Acceptance criteria from the card's checklists and description, one per line.
2. **Design**: data model and migrations, API or routes, UI screens and states (empty, loading, error), permissions.
3. **Steps**: build order in small increments that each leave the app working (for example model → logic → API → UI).
4. **Tests**: unit and feature tests per acceptance criterion.
5. **Rollout**: feature flag, config, seed data, background jobs, anything ops must do.
6. **Docs**: user-facing or developer docs to add or update.
7. **Verify**: every acceptance criterion checked in the running app, suite passes.
